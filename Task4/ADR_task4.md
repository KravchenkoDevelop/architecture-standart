### <a name="_b7urdng99y53"></a>**Передача ставок в кол-центр* 
### <a name="_hjk0fkfyohdk"></a>**Автор: Кравченко Татьяна**
### <a name="_uanumrh8zrui"></a>**Дата:20.10.2025**
### <a name="_3bfxc9a45514"></a>**Функциональные требования**
| **№** | **Действующие лица или системы**   | **Use Case**                        | **Описание**                                                                         |
| :---: | :--------------------------------- | :---------------------------------- | :----------------------------------------------------------------------------------- |
|   1   | Новый клиент, сайт банка           | Просмотр депозитов                  | Клиент видит список доступных депозитов с актуальными ставками.                      |
|   2   | Новый клиент, сайт банка           | Подача заявки на депозит            | Клиент указывает Ф.И.О. и телефон. Заявка передаётся в бэк-офис.                     |
|   3   | Менеджер бэк-офиса, АБС            | Обработка заявки                    | Менеджер анализирует заявку, предлагает особые условия и согласует ставку через АБС. |
|   4   | Новый клиент, отделение банка      | Идентификация                       | Клиент приходит для личной проверки документов перед открытием депозита.             |
|   5   | Система СМС, клиент                | Уведомление о статусе               | После согласования ставки и открытия депозита клиент получает СМС.                   |
|   6   | Существующий клиент, интернет-банк | Просмотр персональных ставок        | Клиент видит актуальные депозиты и персонализированные ставки.                       |
|   7   | Существующий клиент, интернет-банк | Подача заявки через интернет-банк   | Клиент указывает счёт и сумму депозита и подтверждает заявку СМС-кодом.              |
|   8   | Менеджер бэк-офиса                 | Подтверждение заявки интернет-банка | Менеджер проверяет заявку, согласует условия через АБС, инициирует СМС-уведомление.  |
|   9   | Сотрудник кол-центра банка         | Консультация по депозитам           | Сотрудник получает доступ к актуальным ставкам через файлы и консультирует клиента.  |
|   10  | Сотрудник партнёрского кол-центра  | Консультация по депозитам           | Партнёрский кол-центр получает ставки в виде файлов и консультирует клиента.         |
|   11  | Бэк-офис депозита                  | Передача ставок партнёру            | Актуальные ставки выгружаются в файлы и передаются партнёру через SFTP или аналог.   |
### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**
| **№** | **Код** | **Требование**                | **Комментарий**                                                                                                                                                                                                |
| :---: | :------ | :---------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   1   | U       | Удобство интерфейса           | Интерфейс должен быть максимально удобным для клиента, соответствовать системе дизайна банка (цвета, брендированные элементы)                                                                                  |
|   2   | U       | Быстрый отклик операций       | Операции должны выполняться в миллисекунды, минимизация задержки при загрузке справочных данных (<1 секунда)                                                                                                   |
|   3   | R       | Доступность сервисов          | Работа 24/7, доступность не ниже 99,9%, возможность переключения на резервный ЦОД                                                                                                                              |
|   4   | R       | Масштабирование               | Горизонтальное масштабирование интернет-банка; АБС масштабируется вертикально                                                                                                                                  |
|   5   | P       | Производительность            | Минимальная задержка операций, распределение нагрузки между серверами и ЦОД для стабильной работы при увеличении количества запросов                                                                           |
|   6   | S       | Поддерживаемость              | Использование существующих технологий банка (MS SQL, Oracle, внутренние платформы), подготовка документации, возможность будущей миграции интернет-банка на микросервисную архитектуру                         |
|   7   | +R      | Безопасность                  | Шифрование трафика при передаче данных между клиентом и сервером, защита персональных данных (Ф.И.О., телефон, сумма депозита, персонализированные ставки), соблюдение требований идентификации нового клиента |
|   8   | R       | Доступность ставок кол-центра | Сотрудники банка и партнёра имеют актуальные ставки в файлах, возможность быстрой консультации клиентов без перегрузки кол-центра                                                                              |

### <a name="_qmphm5d6rvi3"></a>**Решение**
интеграция системы коллцентров с сайтом ЦБ для ознакомления клиентов текущей ставкой (это чтобы выдать актуальную информацию здесь и сейчас), также можно на расшаренное хранилище поместить xsls файл который при открытии по макросу обращается к ЦБ и наосновании данных цб и формул показывает ставку для клиента


### <a name="_bjrr7veeh80c"></a>**Альтернативы**
данное решение не показывает индивидуальных предложений, можно также как и в кейсе с mvp содать основное апи колл центров и обращаться к промежуточному между апи коллцентров и АБС для получения текущей ставки и индивидуальных предложений для клиентов
